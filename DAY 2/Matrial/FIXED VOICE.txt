Executing بدون Error
أو Executing وفيها Error

9 AM → 5 PM، كل الأيام حسب المادة.

Installation Visit

Violated SLA

5️⃣ Unreachable

لو العميل Unreachable أثناء التركيب:

يوجد تواصل مع العميل خلال 24 Hours.
لا يتم إغلاق TT بالكود 36 إلا في حالة طلب العميل إلغاء الخدمة، مع استثناء Address Need Modification حسب المادة.
لو تم الاتصال بالعميل وتعديل العنوان بحيث يمكن ترتيب الزيارة مرة أخرى → يتم استخدام Close Code 37 في FCC ثم Archive للـTT.
6️⃣ Need Address Modification

لو العنوان غلط أو غير واضح:

نأخذ العنوان كامل من العميل ونراجعه باستخدام Availability Check.

لو العنوان مختلف / خطأ:

Close Code 36
وتوجيه العميل للفرع بالأوراق المطلوبة لتعديل العنوان وعمل Availability Check جديد.

لو العنوان مطابق والرقم متاح:

يتم التأكد من أن الرقم موجود في نفس المبنى.

لو أكد العميل أن الرقم موجود:
Close Code 39

لو الرقم غير موجود:
Close Code 36 + التوجيه للفرع.

نسأله أولًا:

هل استفساره عن نفس المشكلة؟

ولو بنوجه العميل للفرع لازم نبلغه:

Branch Address + Working Hours.

3 Numbers

من الرقم الثاني نبدأ Verification Process.

لو العميل عايز يستفسر عن أكثر من 3 أرقام:

من الرقم الرابع يمكن تحويله إلى IVR.

44️⃣ Legacy Info

1 Hour

8 AM → 8 PM

1 Hour

1 Day.
