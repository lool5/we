🔥 1️⃣0️⃣ TTS — Important Rules

بيانات الـTicket لازم تكون صحيحة:

Router Type
Mobile Number
Problem
باقي البيانات المطلوبة.

قبل:

Re-escalation / Update / Closing

لازم تتأكد إن البيانات صحيحة.

1️⃣1️⃣ Withdraw Ticket

لا يمكن Withdraw إلا لو الـTicket في:

✅ First Level

ولا يمكن Withdraw لو في:

❌ Follow Up
❌ Second Level / Advanced
❌ Pilot SLS
❌ Pilot Follow Up
❌ IU

ولو هتعمل Withdraw:

→ Supporter Group = Current Team
→ Manager Ticket = Own User
→ اضغط Update بعد كل تغيير.

1️⃣2️⃣ Physical Ticket + Logical Problem

لو الـPhysical Ticket موجود عند Third Level والعميل عنده Logical Issue:

أولًا نتأكد إن الـPhysical Issue اتحلت.

لو Logical Problem اتحلت أثناء المكالمة

→ Don't Withdraw

فقط:

→ Update the Ticket.

لو محتاجة Escalation

→ Create IR + Type
→ اكتب الـOld Group + الـNew Case
→ وأضف كل الـTroubleshooting في Comments.

✅ نسجل كل الـNew Troubleshooting.
